# Goals

The outcome each agent works toward.

| Agent | Goal |
|---|---|
| task-scoper | A task that one pass of plan, tests and code can finish: the original, or sub-issues that each are |
| task-planner | A plan that tells the next agents which behaviour to build and what to leave out |
| tdd-maestro | Failing tests that pin down the task's behaviour and nothing more |
| code-fu | The smallest code change that makes those tests pass |
| test-runner | A true account of whether the suite passes, and exactly what fails |
| pr-create | A pull request a reviewer can read without asking questions |
| pr-reviewer | A pull request that meets the task's goal, or comes back with the specific changes it needs |
| merge-evaluator | A grounded yes or no on merging, with every failing condition named |
| merger-mage | The approved pull request merged cleanly into the base branch |
